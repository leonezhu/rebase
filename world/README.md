# 世界公共资产 · 总纲

> 这个世界是所有人的。任何玩家在支线里遇见的人物、学到的功法、得到的法宝、踏过的地点——只要登记在案，就成为**公共资产**：别人可以遇到同一位 NPC、学同一部功法、踏进同一个秘境。
>
> 故事之间因此有了交集。你的经历，是别人路上的风景。

## 目录结构

```
world/
  locations/          # 地点：秘境、城镇、险地
    <id>.yaml
  npcs/               # 人物：修士、散修、异人（NPC 由 bot 代管）
    <id>.yaml
  gongfa/             # 功法池：可被习得的功法
    <id>.yaml
  artifacts/          # 法宝池：可被持有的法宝
    <id>.yaml
  events/             # 事件池：探索时的随机遭遇模板
    <id>.yaml
  lore/               # 世界观碎片：大事件、传闻、时代注脚
    <id>.yaml
```

## 资产入库的途径

1. **叙事产出**：玩家与 Agent 的对话中生成的新功法/法宝/地点/NPC，Agent 整理成 yaml 入库（来源注明哪个玩家的哪段经历）
2. **战利品转移**：斗法/讨伐获胜，败方的功法与法宝（未损坏的）转入胜方支线，同时资产档案里追加一条「持有者史」
3. **随机事件生成**：引擎把资产池里的东西编进遭遇模板，随机投放给任何玩家

## 资产共享规则

- **功法**：入库后任何人可通过藏经阁/奇遇习得（同一部功法，各自的修行进度独立）
- **法宝**：唯一性看档案 `unique: true/false`。唯一的法宝同时只有一个主人；非唯一的可复现（成对、成批、师门同款）
- **NPC**：公共 NPC 的状态全局一致（境界、所在地），但与每个玩家的关系独立记录在玩家自己的档案里
- **地点**：公共地点人人可至；地点内的事件由事件池决定
- **来历不可改**：`origin` 字段是资产的历史，append-only。谁的支线产出的资产，永远带着那条支线的印记

## 铁律

- 资产档案只由 bot 与 Agent 写，玩家经 PR 参与也算 Agent 整理后入库
- 玩家档案里的 `gongfa/artifacts` 只是**持有记录**，资产本体在 world/——删除玩家档案不影响世界
- 数值写入只信 `github-actions[bot]`（与玩家档案同规）
